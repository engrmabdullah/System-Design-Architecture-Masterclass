# System Design & Software Architecture — الشرح العربي الكامل

عرض تقديمي تفاعلي (HTML + CSS + JavaScript) لتعلّم تصميم الأنظمة ومعمارية البرمجيات بالعربي،
مع الاحتفاظ بكل المصطلحات التقنية بالإنجليزية، وتطبيقات عملية على **.NET / ASP.NET Core**.

> الكورس ده **للتعلّم والفهم** — مش تحضير لمقابلات عمل. كل مفهوم بيتشرح عشان تفهمه وتطبّقه،
> مش عشان تحكيه لحد.

## التشغيل

افتح `index.html` بأي متصفح. مفيش build ولا server ولا تنصيب.

> الخطوط بتتحمّل من Google Fonts. من غير نت الصفحة تشتغل عادي بخطوط النظام البديلة.

## المميزات

### 🔊 النطق الصوتي + القاموس
اضغط على **أي مصطلح إنجليزي** جوّه أي سلايد:
- ينطقه بصوت **رجّالي، بطيء وواضح** (المحرك بيختار صوت ذكر تلقائيًا من أصوات جهازك)
- تظهر بطاقة فيها **المعنى بالعربي + الاسم الكامل + الشرح + مثال**
- اضغط على نفس المصطلح تاني بسرعة ⇒ ينطقه **أبطأ**

القاموس في [assets/js/glossary.js](assets/js/glossary.js) وفيه **290+ مصطلح**.
تقدر تضيف عليه بنفس الشكل (المفتاح بحروف صغيرة):

```js
"consistent hashing": { ar: "التجزئة المتسقة", full: "Consistent Hashing",
  desc: "الشرح بالعربي…", eg: "مثال قصير." },
```

### 🔍 تفكيك الأسطر التقنية
أي سطر مختصر زي `10M DAU, 500K peak concurrent` أو `p99 latency < 200ms @ 5000 RPS`
بيتفكّك **كلمة كلمة** في جدول، وفي الآخر جملة عربية بتلمّ المعنى كله.

### ✏️ تمارين بحلول مخفية
كل مفهوم وراه تمرين. جاوب على ورقة الأول، وبعدين اضغط «شوف الحل».
الحل بيشرح **ليه** الإجابة كده والدرس المستفاد — مش بس الرقم.

### 🎯 نقاط مراجعة
في آخر كل قسم فيه checkpoint بأسئلة لازم تقدر تجاوب عليها قبل ما تكمل.

## التعديل والإضافة

كل سلايد هي `<section class="slide" data-title="...">`.
المحرك بيبني شريط التقدّم والفهرس وشريط التنقّل والنطق تلقائيًا — ماتكتبهمش بإيدك.

اقرأ [assets/COMPONENTS.md](assets/COMPONENTS.md) الأول: فيه كل الكلاسات المتاحة
(`termcard`, `decode`, `exercise`, `example`, `checkpoint`, `callout`, `math`, `flow`, `code`, …)
بأمثلة جاهزة للنسخ. و[assets/BRIEF.md](assets/BRIEF.md) فيه قواعد المحتوى.

**قواعد لازم تلتزم بيها:**
- ماتضفش `<style>` ولا CSS جديد — استخدم الكلاسات الموجودة بس.
- كل مصطلح إنجليزي جوّه نص عربي يتلف في `<span class="term">` — عشان يشتغل عليه النطق والقاموس.
- كل رقم أو كلمة لاتينية جوّه فقرة عربية تتلف في `<span class="ltr">`.
- جوّه `<pre><code>` اعمل escape لـ `<` كـ `&lt;` و `&` كـ `&amp;`.
- أي سطر تقني مختصر لازم يتبعه `.decode` يفكّكه.

بعد أي تعديل:

```bash
node assets/validate.js        # بنية الملفات + متطلبات المحتوى
node assets/check-glossary.js  # سلامة القاموس
```

`validate.js` بيفشّل الملف لو: فيه HTML مكسور، أو رابط ميت، أو `<style>`،
أو escaping غلط في الكود، أو أقل من 40 سلايد / 8 تمارين / 6 تفكيك / 5 أمثلة / 4 مراجعات،
أو أي صياغة عن مقابلات العمل.

## طريقة المذاكرة الموصى بها

1. **ذاكر بالترتيب.** الموديولات مبنية فوق بعض، والموديول 01 هو أساس كل اللي بعده.
2. **ماتعديش تمرين.** جاوب على ورقة قبل ما تفتح الحل. لو الحل فاجأك، ارجع اقرا المفهوم تاني.
3. **اضغط على كل مصطلح مش واضح.** المصطلحات هي لغة المجال — لازم تعرف تنطقها وتفهمها.
4. **طبّق على نظام حقيقي عندك** بعد كل موديول: احسب الـ QPS الحقيقي، حدّد الـ NFRs بالأرقام،
   دوّر على نقاط الفشل الوحيدة.
5. في دراسات الحالة (13–15) قف عند سلايد **«جرّب تحلّها الأول»** وحاول تحلّها على ورقة قبل ما تشوف الحل.
